# AI-assisted development

FakeDiscord was developed with extensive assistance from **ChatGPT by OpenAI**.

The repository owner directed the product decisions, requirements, testing scenarios and final acceptance of changes. ChatGPT was used as an implementation partner across the project.

## Areas assisted by ChatGPT

ChatGPT contributed to:
- implementation and refactoring of C++, Rust and shell code;
- debugging Windows and Arch Linux behavior;
- design of the private-server pairing/allowlist model;
- direct peer-to-peer file-transfer features;
- PTT input handling on Windows and Linux/Wayland;
- launcher UI work for Win32 and Qt;
- test creation and regression analysis;
- build and installation scripts;
- update/release tooling;
- technical documentation and repository preparation.

## Human direction and review

All changes were requested, reviewed and tested under human direction. The project owner remains responsible for deciding what ships and for validating behavior on the target systems.

This disclosure is intentionally explicit so contributors and users can understand how the project was produced.
